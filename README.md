# Calculator on Rust

> This is a purely educational project created with minimal knowledge of the Rust language. The code contains multiple serious errors and architectural flaws. It was written solely to evaluate the complexity of the language and its potential for future development. Do not use this code in production environments.

A simple command-line calculator built with Rust. It supports basic arithmetic operations and runs in a continuous loop until the user chooses to exit.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division, and remainder
- Floating-point number support
- Input validation for numbers and operations
- Division by zero protection
- Continuous execution mode

## Requirements

- Rust programming language (latest stable version)
- Cargo package manager

## Installation

1. Clone the repository:
```git clone https://github.com/WerLickGit/Calculator.git```
```cd Calculator```

2. Build the Project:
```cargo build --release```

3. Usage:
```cargo run```
