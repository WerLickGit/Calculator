# Calculator on Rust

A simple command-line calculator built with Rust. It supports basic arithmetic operations and runs in a continuous loop until the user chooses to exit.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division, and remainder
- Floating-point number support
- Input validation for numbers and operations
- Division by zero protection
- Continuous execution mode

## Requirements

- Rust programming language (latest stable version)
- Cargo package manager
